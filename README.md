# STREET KUMITE · 街頭拳鬥

網頁版 2D 格鬥遊戲，機制仿 90 年代街機格鬥：六鍵、搓招必殺技、連段取消、超必殺、投技與拆投、暈眩、frame data。

> **原創同人作品**：8 位角色＋拳帖四天王、12 個舞台、美術、招式名稱、音效與音樂都是原創。美術用 AI 生成，音效與音樂由程式即時合成。
> 本作沒有使用任何商業格鬥遊戲的素材、程式碼或資料，與 Capcom 及《Street Fighter》系列無關。
> 遊戲機制本身（六鍵、搓招、hitbox、frame data 等）屬於通用設計，不受著作權保護。

## 執行

免打包的 ESM 專案，不需要 npm，也不需要 build。因為用了 ES module，不能直接雙擊 `index.html`，要透過靜態伺服器開啟：

```bash
python3 serve.py        # http://localhost:5320
```

推到 `main` 後，`.github/workflows/deploy.yml` 會把 repo 內容原樣部署到 GitHub Pages（線上版：https://wenbatman33.github.io/street-kumite/）。

## 模式

| 模式 | 說明 |
| --- | --- |
| 街機模式 | 大會序章與角色序章 → 世界地圖飛往下一國 → 依序挑戰其他角色（各在對手家鄉），第 7 戰是宿敵（宿命之戰），之後連戰拳帖四天王：阿特拉斯 → 賽特 → 沃坎 → 最終王鐵心；輸了有 CONTINUE 倒數，通關播放角色專屬結局與製作名單，選角畫面會標 ★ |
| 自由對戰 CPU | 自選自己、對手與舞台，CPU 難度 EASY / NORMAL / HARD / MASTER（在「設定」調整） |
| 2P 本機雙人 | 同一鍵盤左右分邊，或接兩支手把 |
| 格鬥家 | 八位角色的出身、基本資料與背景故事 |
| 訓練模式 | 假人動作（站／蹲／跳／CPU／錄製重播）、防禦設定、自動回血、無限量表、判定框、frame data（發生／持續／硬直／有利幀）、輸入紀錄 |

## 操作

| 動作 | 單人／訓練 | 2P 左側 | 2P 右側 | 手把 |
| --- | --- | --- | --- | --- |
| 移動 | WASD 或方向鍵 | WASD | 方向鍵 | 十字鍵／左搖桿 |
| 輕／中／重 拳 | U I O | T Y U | I O P（或 Num 4 5 6） | X Y RB |
| 輕／中／重 腳 | J K L | G H J | K L ;（或 Num 1 2 3） | A B RT |
| 暫停／訓練選單 | Esc | Esc | Esc | START |

- **手機／平板**：橫放後左下是虛擬搖桿、右下是六鍵；按在兩顆鍵中間等於同按（輕拳+輕腳投技）。右上有暫停、訓練重設鍵，左上可切全螢幕（iPhone 請用「加入主畫面」）。「設定」可開啟**簡易必殺**：多一顆 SP 鍵，SP + 方向直接出必殺技（免搓招、免蓄力），單按 SP 是超必殺。觸控按鍵位置可在 DEV 工具「版面」拖曳調整（手機／平板分開）。
- **防禦**：按住「後」。蹲防用「後下」；下段技要蹲防，跳攻擊與 TORA 的虎落踵（中段）要站防。
- **投技**：近身時「輕拳+輕腳」同按，或「前/後 + 重拳」。被抓瞬間輸入同樣指令可以拆投。
- **取消**：普通技命中或被防時可以取消成必殺技，必殺技可以再取消成超必殺（需要量表全滿）。
- **訓練模式**：按 R 重設位置。按住 ← 或 → 再按 R，會把假人放到牆角。

### 角色與招式（指令以面向右方為準）

全員原創，玩法類型對應經典格鬥遊戲的角色分類。

| 角色 | 類型 | 必殺技 | 超必殺 |
| --- | --- | --- | --- |
| **TORA 虎牙** | 均衡（空手道） | 虎咆彈 ↓↘→+P／昇虎拳 →↓↘+P／虎落踵（中段）↓↙←+K | 雷虎轟 ↓↘→↓↘→+P |
| **VERA 薇拉** | 速攻（卡波耶拉） | 疾風腳 ↓↘→+K／月輪 →↓↘+K／銀河旋 ↓↙←+K | 嵐舞 ↓↘→↓↘→+K |
| **BAATAR 巴特爾** | 投技（蒙古摔角） | 草原大地摔（指令投）360+P／鷹舞（對空）→↓↘+P／蠻牛衝撞（霸體）↓↘→+K | 天地崩 ↓↘→↓↘→+P |
| **SKYE 史凱** | 蓄力（極地救援） | 寒冰飛盤 按住←再→+P／霜柱（遠距對空）按住↓再↑+K／冰面滑鏟 按住←再→+K | 暴風雪 ↓↘→↓↘→+P |
| **KAGERO 陽炎** | 忍者（速度） | 苦無（空中可）↓↘→+P／月影斬 →↓↘+K／陽炎遁（瞬移）↓↙←+K；可二段跳 | 影舞 ↓↘→↓↘→+P |
| **SHEN 沈** | 長棍牽制（武僧） | 龍突 ↓↘→+P／旋風棍（對空）→↓↘+P／撐竿飛踢（中段）↓↙←+K | 百裂棍 ↓↘→↓↘→+P |
| **DRAKE 德雷克** | 力量（拳擊） | 重砲直拳（霸體）↓↘→+P／衝天勾拳 →↓↘+P／連環勾拳 ↓↙←+P | 最終鐘聲 ↓↘→↓↘→+P |
| **KANYA 甘雅** | 近身（泰拳） | 飛膝 ↓↘→+K／衝天膝（對空）→↓↘+K／連環肘（末段中段）↓↙←+P | 迦樓羅 ↓↘→↓↘→+K |

- **360 指令投**：搖桿轉一圈（前、下、後、上都要經過）再按拳。轉到「上」的瞬間按拳也算，不會跳起來。
- **蓄力**：按住方向約 0.7 秒，再往反方向推並按鍵。蹲防（按住後下）時會同時累積兩種蓄力。
- **霸體**：出招中可以硬吃一下攻擊不被打斷，只受一半傷害。
- **瞬移**：陽炎遁用輕腳往前、中腳繞到對手背後、重腳往後拉開。

## 畫面風格

- **像素畫風**：舞台與特效 3 倍像素（427×240 低解析畫布），角色與頭像 2 倍像素並在減色前銳化，保留臉部與服裝細節；文字、血條維持高解析。倍率、色數、銳化都可在 DEV 工具調整（倍率 1 = 關閉）。
- **鏡頭**：對戰鏡頭以地面為軸拉近 1.2 倍，角色佔滿畫面高度，跳躍能到畫面上緣。
- **前中後景**：背景視差捲動、地板逐列透視捲動，前景物件（燈籠、攤車、棕櫚葉、森巴鼓、沙包…）捲動比角色快，從鏡頭前滑過。
- **世界地圖**：選角畫面上方是世界地圖，標出各國國旗與位置；街機模式每戰之間畫出飛往下一國的路線。
- **K.O. 吐血**：K.O. 與重擊時口中噴出血沫，落地留下血跡；結算與 CONTINUE 畫面的敗者是鼻青臉腫的落敗頭像。
- **配樂**：13 首原創 FM 街機風曲子，戰鬥曲 156～174 BPM，民族風味放在主奏樂器與打擊樂（森巴鼓、馬頭琴、三味線、二胡、泰國簧管與小鈸、拳擊鐘…）。
- **地板透視捲動**：舞台地板逐列用不同速度捲動，角色腳下那一列與角色同速，不會滑步。
- **各國舞台動態元素**（`src/stagefx.js`）：台北雨夜與攤販蒸氣、巴西海鷗與海面波光、蒙古老鷹與雲影、挪威飄雪與極光、日本櫻花與燈籠、中國香煙與山嵐、倫敦聚光燈與煙霧、曼谷天燈；重擊與 K.O. 時觀眾閃光燈、彩紙反應。
- **打擊感**：像素風星形火花（依輕中重分級、必殺技帶角色色）、重擊速度線、沿打擊方向的震動、重擊鏡頭衝擊縮放、受擊滑行揚塵（依舞台換成雪、沙、水花）、跳入攻擊專屬低頻音、突進／升龍／招牌跳躍技的殘影。
- **投技**：抓住瞬間雙方定格 → 一個動作甩出 → 重摔，抓到後約 0.45 秒落地（前投摔在前方、按住後為後投摔到背後）。
- **跳躍招式**：輕＝半伸、出得快；中＝全伸；重＝較慢、判定大、帶殘影。招牌跳躍重攻擊：TORA 空中虎落踵、VERA 空中疾風腳、BAATAR 泰山壓頂、KAGERO 空中月影斬、SHEN 撐竿飛踢、DRAKE 飛身重砲、KANYA 空中飛膝。

## DEV 微調工具

開關方式：按 **F2** 或 **`**，或點右下角 ⚙。

- **版面 HUD**：血條、計時器、頭像、量表、連段數等，都可以直接在畫面上用滑鼠拖曳，也可以用滑桿或顏色選擇器調整，即時生效。
- **舞台／角色大小**：地面高度、角色身高、背景縮放與位置、視差。
- **角色 sprite**：每個動畫的位移 X/Y 與縮放，修正個別動作的對位。
- **招式 frame data**：
  - 時間軸、判定開始與結束的 tick、傷害、硬直、推距、上中下段、擊倒。
  - 勾選「逐 tick 預覽」後，P1 會停在該招的指定 tick，可以直接拖曳紅色判定框（拖右緣調寬度）。
  - 判定框預設會依 sprite 最前端的手腳自動對齊。關閉「貼齊 sprite」後改用手動數值。
- **🎬 跳到畫面**：標題、格鬥家檔案、VS（一般／宿敵戰）、結算勝敗、CONTINUE、角色結局、製作名單、Demo 對戰，可指定自己與對手。
- **🖼 各畫面版面**：標題、選角、VS、劇情、結算的頭像位置與大小、文字框位置等。
- **🟦 像素畫風**、**🌏 舞台動態元素**（各舞台的雨雪數量、閃光燈頻率、開關）、舞台地板起點與揚塵顏色、受擊抖動與鏡頭衝擊強度。
- **遊戲狀態／觸發**：暫停（按 `.` 逐格）、慢動作、顯示判定框；可直接觸發 K.O.、時間到、暈眩、超必殺、勝利姿勢、量表全滿、低血量等畫面。
- **💾 匯出**：把所有調整輸出成 JSON（同時下載並複製到剪貼簿）。貼給 Claude 並說「我調好了，鎖定」，數值就會寫回原始碼。
  調整也會暫存在瀏覽器 localStorage；要回到原始碼數值，按「↺ 清除本機覆寫」。

## 素材管線（AI 生圖）

| 步驟 | 指令／檔案 |
| --- | --- |
| 1. 角色外觀、每個動作的逐格姿勢描述 | `scripts/asset_manifest.json` |
| 2. 透過 `codex exec` 內建 image_gen 生圖：先產角色設定圖，再附上設定圖產所有動作，以維持外觀一致；已存在的會跳過。舞台前景物件（`prop/`）、世界地圖（`extra/`）也在這裡 | `node scripts/gen_assets.mjs --jobs 2`（可加 `--only tora/hk,vera,prop` 只跑指定項目；預設模型 `gpt-6.1-sol`，可用 `--model` 改） |
| 2b. 落敗頭像（以現有頭像為參考圖） | `node scripts/gen_hurt_portraits.mjs --jobs 2` |
| 3. 洋紅去背、依格切圖、腳底與身體柱對齊、依站姿參考格統一縮放、打包 atlas | `python3 scripts/process_sprites.py`（可加 `--only tora,props,hurt,stages,extra`） |

- 原圖放在 `assets_src/raw/`（約 100MB，不進版控）；檢查用接觸表在 `assets_src/review/`。遊戲實際使用的是 `assets/sprites/<角色>/atlas.json` 與 `.webp`。
- 要重畫某個動作：刪掉 `assets_src/raw/<角色>/<動作>.png`，或修改 manifest 的描述，再重跑步驟 2 和 3。
- 每張動作圖的第 1 格都是標準站姿，用來統一不同張圖的角色大小。

## 檔案結構

```
index.html            進入點（import map 載入 vendor/lil-gui）
serve.py              開發伺服器（關閉快取）
src/
  main.js             畫布縮放、60Hz 固定步進迴圈
  config.js           LAYOUT / STAGES / PHYS / FX / 按鍵配置（DEV 工具調整的對象）
  input.js            鍵盤、手把、方向歷史、搓招判定、按鍵緩衝
  fighter.js          角色狀態機、受擊與防禦、判定框（含 sprite 自動對齊）
  battle.js           回合流程、碰撞、飛行道具、投技、鏡頭、訓練 frame data
  controllers.js      人類／CPU AI／訓練假人 控制器
  render.js           舞台、角色、特效、HUD、訓練資訊
  scenes.js           標題（閒置輪播序章與 Demo）、選單、選角、劇情、VS、對戰、暫停、結算、CONTINUE、結局、製作名單、格鬥家檔案、說明、設定
  story.js            大會序章、角色檔案、宿敵、台詞、結局、舞台所在國家
  pixel.js            像素畫風：減色、低解析畫布、像素化圖片／影格快取
  stagefx.js          各國舞台動態元素與觀眾反應
  audio.js            Web Audio 合成音效與背景音樂、回合語音
  devtools.js         DEV 微調工具
  worldmap.js         世界地圖、國旗、移動路線
  chars/              角色資料（frame data、必殺技）；atlas / seth / volkan / tesshin 為拳帖四天王
assets/               處理後的遊戲素材
scripts/              生圖與後處理腳本
```
